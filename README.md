# java-racingcar-precourse

---

## 기능 목록

### 1. 입력 기능
- [x] 자동차 이름 입력받기
    - 입력 메시지: "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)"
    - 예시: pobi,woni,jun
- [x] 쉼표(,)를 기준으로 자동차 이름 분리하기
- [x] 시도 횟수 입력받기
    - 입력 메시지: "시도할 횟수는 몇 회인가요?"
    - 예시: 5

### 2. 입력 검증 기능
- [x] 자동차 이름이 5자 이하인지 검증
    - 5자 초과 시 IllegalArgumentException 발생
- [x] 자동차 이름이 비어있지 않은지 검증
    - 빈 문자열이나 공백만 있을 경우 IllegalArgumentException 발생
- [x] 시도 횟수가 숫자인지 검증
    - 숫자가 아닐 경우 IllegalArgumentException 발생
- [x] 시도 횟수가 양수인지 검증
    - 0 이하일 경우 IllegalArgumentException 발생

### 3. 자동차 생성 기능
- [x] 입력받은 이름으로 자동차 객체 생성
- [x] 각 자동차의 초기 위치를 0으로 설정
- [x] 여러 대의 자동차를 리스트로 관리

### 4. 게임 진행 기능
- [x] 입력받은 횟수만큼 라운드 반복
- [x] 매 라운드마다 모든 자동차에 대해 이동 시도
- [x] 0에서 9 사이의 무작위 값 생성 (Randoms.pickNumberInRange 사용)
- [x] 무작위 값이 4 이상이면 전진
- [x] 무작위 값이 4 미만이면 정지
- [x] 전진 시 자동차의 위치 +1

### 5. 출력 기능
- [x] 매 라운드 실행 결과 출력
    - 형식: "자동차이름 : ---" (위치만큼 - 출력)
    - 각 자동차 한 줄씩 출력
    - 라운드 사이에 빈 줄 출력
- [x] 실행 결과 헤더 출력 ("실행 결과")
- [x] 최종 우승자 출력
    - 단독 우승: "최종 우승자 : pobi"
    - 공동 우승: "최종 우승자 : pobi, jun" (쉼표로 구분)

### 6. 우승자 판정 기능
- [x] 모든 자동차 중 최대 위치 찾기
- [x] 최대 위치에 있는 모든 자동차 찾기
- [x] 우승자가 여러 명인 경우 쉼표(,)로 구분

### 7. 예외 처리
- [x] 잘못된 입력 시 IllegalArgumentException 발생
- [x] 예외 발생 시 애플리케이션 종료
- [ ] 에러 메시지 출력 (선택사항)

## 구현 순서 (예상)

1. Car 클래스 구현 (자동차 한 대)
2. InputValidator 클래스 구현 (입력 검증)
3. Cars 클래스 구현 (자동차 목록 관리)
4. OutputView 클래스 구현 (출력)
5. RacingGame 클래스 구현 (게임 진행)
6. Application 클래스 수정 (메인)
7. 테스트 코드 작성
